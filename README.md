# Sovereign System

**Measured intelligence. Structural stability.**

Project Guy exists to restore human cognitive agency in an adversarial digital world. In an environment engineered to capture attention and manipulate cognition, we are building a sovereign, on-device AI that functions as a mental prosthetic, not a rented assistant. 

We do not believe ethics can be a policy layer. Alignment must be embedded in architecture, making it inseparable from the system’s survival. Your cognition is not a product. Trust must be engineered, not promised.

### Radical Legibility & Open Source
Protection must never become manipulation. For an AI architecture to truly serve the human mind, its filters must be labeled, its memory inspectable, and its system capable of explaining itself. 

**Radical legibility demands open architecture.** 
We are currently building the base layer of this infrastructure. Once the structural stability of the ecosystem is verified, the core repositories will be open-sourced here.

### The Architecture
The sovereign ecosystem is built on four interdependent layers:

#### 1. Eclipse (Protecting Perception)
**Protection before perception.** Eclipse is the perceptual interposition layer. It sits between the device and the user's senses, functioning as a cognitive immune system. It allows users to control what reaches their eyes and ears: blurring, muting, or flagging hostile information before it affects them. 

#### 2. Libraric (Preserving Meaning)
**Built to remember.** The Libraric Layer is a private, on-device memory system. It organizes lived experiences into immutable, meaningful structure. Memory is completely inspectable and locally held, ensuring the system grows with the user without treating their past as harvestable data.

#### 3. OSP (Anchoring Reality)
**Proof before narrative.** Open Source Panopticon (OSP) cryptographically verifies real-world events at the exact moment they are recorded. In a world flooded with synthetic media, OSP functions as unflinching public infrastructure, signing proof before it can be altered.

#### 4. Project Guy (Measured Intelligence)
**The Sovereign AI.** Guy thinks within the protected, preserved, and verified foundation of the other three pillars. It is an on-device architecture designed from the mandate of accessibility. It does not reach outward. It does not report upward. It remains within your boundaries.

### Accessibility is Alignment
We design for the most vulnerable first. If an AI system is not safe for trauma survivors, neurodivergent individuals, and children, it is not safe for anyone. Accessibility is not a feature; it is the structural standard.
